# TaskFlow - Gerenciador de Tarefas (Flask)

Projeto de exemplo para a disciplina de Engenharia de Software.

## Objetivo
Criar um sistema web básico para gerenciamento de tarefas (CRUD) usando Flask, com testes automatizados e pipeline CI via GitHub Actions.

## Estrutura
/src - código fonte do app  
/tests - testes pytest  
/docs - documentação e diagramas  
.github/workflows/ci.yml - workflow para rodar testes
